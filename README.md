Circular Curve Calculator

Project Description

This project is a Python-based application developed to simplify the computation of circular curves used in surveying and road engineering.

Objectives

- To automate circular curve calculations.
- To improve accuracy in surveying computations.
- To reduce manual calculation time.
- To provide reliable results for engineering surveying applications.

Programming Language

Python

Main Program

"circular_curve_calculator.py"

Application

The program is designed to assist surveyors and engineering students in circular curve computations.
